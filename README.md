# GPS Speed

Минимальный спидометр на Kotlin без внешних зависимостей. Скорость берётся с GPS.

## Возможности

- Крупная цифра скорости на чёрном фоне, экран не гаснет
- Единицы: км/ч → миль/ч → м/с → узлы
- Максимальная скорость и сброс
- Точность GPS и статус (нет разрешения / GPS выключен / ждём сигнал)
- Значения ниже 0,5 м/с считаются нулём

## Сборка в Android Studio

1. File → Open → папка `GpsSpeed`
2. Дождаться синхронизации Gradle
3. Run на телефон с отладкой USB
4. Разрешить геолокацию, проверять на улице

## APK через GitHub Actions

Загрузите содержимое этой папки (включая `.github`) в репозиторий GitHub.
Вкладка Actions → артефакт `app-debug` → `app-debug.apk`.
